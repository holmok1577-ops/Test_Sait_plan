# Ясно — список задач

Небольшой адаптивный To-Do List для тестового задания. HTML, CSS и JavaScript без фреймворков, внешних шрифтов и зависимостей во время работы сайта.

## Возможности

- Добавление задачи кнопкой или клавишей Enter.
- Отметка выполнения и возврат задачи в работу.
- Удаление задачи.
- Сохранение текста и статуса в localStorage после перезагрузки.
- Фильтры «Все», «В работе», «Готово», счётчик и прогресс.
- Мобильная версия, клавиатурное управление и подписи для скринридеров.
- Проверка пустого ввода, ограничение 300 символов и безопасное отображение текста.
- Сообщения об ошибках чтения или записи хранилища.

## Запуск

Нужен Node.js 18 или новее. Для запуска приложения установка пакетов не требуется:

```sh
npm start
```

Откройте http://127.0.0.1:4173. Сервер предназначен для локальной разработки.
Сайт — статические файлы из `dist/`, его можно разместить на любом статическом хостинге.

## Проверки

```sh
npm ci
npx playwright install chromium
npm run check
npm test
```

Playwright проверяет сценарии на desktop и мобильном viewport: создание, переключение статуса, фильтры, удаление, сохранение после перезагрузки, пустой ввод, HTML как обычный текст, длинную задачу, повреждённое хранилище и ошибку записи. Тесты создают скриншоты пустого и заполненного списка в `test-results/`.

## Структура

- `dist/` — готовый сайт: HTML, CSS, JS и иконка.
- `scripts/serve.cjs` — локальный HTTP-сервер без зависимостей.
- `tests/` — браузерные проверки.
- `PLAN.md` — план и критерии приёмки.

## Хранение данных

Задачи хранятся только в текущем браузере, в ключе `yasno.tasks.v1`. Данные не отправляются на сервер и не синхронизируются между устройствами или вкладками. Очистка данных сайта удаляет список. В приватном режиме срок хранения определяется браузером. При повреждении сохранённых данных приложение предупреждает пользователя и не перезаписывает их; изменения текущей сессии в этом случае не сохраняются.

## AI-инструменты

Проект разработан с помощью **OpenAI Codex**: составление плана, проектирование интерфейса, реализация HTML/CSS/JavaScript, написание и запуск проверок, подготовка документации. Плагин **Sites** использован для подготовки размещения демо. Playwright — инструмент тестирования, не AI-инструмент.

## GitHub и публичное демо

Репозиторий подготовлен локально. Для публикации войдите в свой GitHub и выполните из папки проекта:

```sh
gh auth login
gh repo create yasno-todo --public --source=. --remote=github --push
```

Для бесплатного демо на GitHub Pages: в Settings → Pages выберите источник **GitHub Actions**, затем запустите workflow **Deploy GitHub Pages** во вкладке Actions. Workflow публикует папку `dist/` и показывает итоговый URL. В приватных репозиториях доступность Pages зависит от тарифа.

Для ответа работодателю: «Проект: [ссылка на GitHub]. Работающий сайт: [публичная ссылка]. При разработке использовал OpenAI Codex для планирования, реализации интерфейса и функциональности, тестирования и подготовки документации».
