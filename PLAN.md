# План реализации

1. Выбрать простой стек: HTML, CSS, JavaScript без фреймворка и серверной базы данных.
2. Создать адаптивный интерфейс на русском с формой, списком, фильтрами и прогрессом.
3. Реализовать добавление, выполнение/возврат в работу, удаление. Хранить задачи в localStorage.
4. Добавить валидацию ввода, безопасный вывод текста, доступные подписи, клавиатурное управление и уведомление об ошибках хранения.
5. Проверить полный жизненный цикл задачи с перезагрузкой, крайние случаи и мобильную ширину в браузере.
6. Описать запуск, ограничения и AI-инструменты; подготовить Git и публикацию.

## Приёмка

- Новая задача появляется по кнопке и по Enter.
- Пустая задача не добавляется.
- Отметка выполнения переключается в обе стороны.
- После обновления страницы сохраняются текст и статус.
- Удалённая задача не возвращается после обновления.
- Интерфейс помещается на мобильном экране, длинный текст переносится.
- README содержит сведения об AI-инструменте и инструкции запуска.
